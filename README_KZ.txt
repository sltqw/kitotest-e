KITOTEST — толық жоба

Құрылымы:
- public/index.html — сайттың интерфейсі
- server.js — Node.js сервері және API
- package.json — қажетті кітапханалар мен іске қосу командасы
- render.yaml — Render-ге орналастыру конфигурациясы
- .env.example — жергілікті орта айнымалыларының үлгісі

ЖЕРГІЛІКТІ ІСКЕ ҚОСУ (Node.js 18+):
1. ZIP архивті толық шығарыңыз.
2. Осы бумада терминал/Command Prompt ашыңыз.
3. npm install
4. .env.example файлын .env деп көшіріп, ішіндегі мәндерді өзгертіңіз:
   - JWT_SECRET: кемінде 32 таңбалы кездейсоқ құпия мән.
   - ADMIN_CODE: дәл 32 таңбалы бөлек әкімші коды.
5. Windows PowerShell-де айнымалыларды .env файлынан автоматты оқу үшін dotenv пакет қажет емес: оларды Render Environment немесе терминал арқылы орнатыңыз.
   PowerShell мысалы:
   $env:JWT_SECRET='ӨЗІҢІЗДІҢ_32+_ТАҢБАЛЫ_ҚҰПИЯ_МӘНІҢІЗ'
   $env:ADMIN_CODE='ДӘЛ_32_ТАҢБАЛЫ_ӘКІМШІ_КОДЫ'
   npm start
6. Браузерде http://localhost:3000 ашыңыз.

RENDER + GITHUB:
1. GitHub репозиторийіне архив ішіндегі файлдар мен public бумасын жүктеңіз.
2. Render → New → Web Service → репозиторийді таңдаңыз.
3. Build Command: npm install
4. Start Command: npm start
5. Environment ішіне JWT_SECRET (кемінде 32 таңба) және ADMIN_CODE (дәл 32 таңба) қосыңыз.
6. Deploy жасаңыз.

ҚАУІПСІЗДІК:
- Құпиясөздер bcrypt хэш түрінде сақталады; plainPassword сақталмайды және админге көрсетілмейді.
- Админ панелі тіркелген аккаунттардың аты, email-і, тіркелген күні туралы мәлімет көрсетеді және аккаунтты өшіруге мүмкіндік береді.
- ADMIN_CODE пен JWT_SECRET-ті GitHub-қа немесе HTML файлына жазбаңыз. Оларды тек сервердің Environment айнымалыларында сақтаңыз.
- Google кіруін қолдансаңыз, GOOGLE_CLIENT_ID мәнін Render Environment ішіне енгізіңіз.

ЕСКЕРТУ:
Бұл жоба файлдық JSON дерекқорын қолданады. Render-дің ephemeral дискісінде деректер қайта іске қосылғанда жоғалуы мүмкін. Тұрақты өндірістік пайдалану үшін Render Persistent Disk немесе PostgreSQL сияқты тұрақты дерекқорды баптаңыз.
